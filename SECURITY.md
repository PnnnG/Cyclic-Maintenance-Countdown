# Security policy

## Supported versions

Security fixes are provided for the latest published Maintenance Countdown release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include secrets in logs or screenshots. Use GitHub's [private vulnerability reporting](https://github.com/PnnnG/Maintenance-Countdown/security/advisories/new) instead.

Include the affected version, Home Assistant version, impact, reproduction steps, and any proposed mitigation. Reports will be acknowledged as soon as practicable. A confirmed issue will be coordinated privately until a fix and release guidance are ready.
